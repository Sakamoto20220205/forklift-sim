# フォークリフト誘導訓練

倉庫内の荷物を指定の置き場へ運ぶ、フォークリフトの安全訓練ゲームです。
ブラウザだけで動きます（インストール不要・iPhone / Android / PC 対応）。

**▶ 遊ぶ：https://sakamoto20220205.github.io/forklift-sim/**

## タイトル画面とメニュー

開くとタイトル画面（フォークリフトと仲間たちの影絵）が出ます。画面をタップすると、メニューが出ます。入口は目的別に「あそぶ」と「まなぶ」の2つです。

| メニュー | 内容 |
|---|---|
| あそぶ | 子ども・一般向け。荷物を運んでごほうびを集めます |
| まなぶ | 技能講習の予習・復習、講義向け。作業別の練習と講師用の機能 |
| つづきから | 途中でやめたゲームを、やめたところから再開します（ブラウザを閉じても残ります） |
| 図鑑・コレクション | おじゃま虫図鑑、コレクション（飾り棚と水槽）、実績、自己ベスト |
| 設定 | 操作方法、初心者コース、上方ビュー、補助表示、AI誘導員の補助、効果音。端末に保存されます |

**あそぶ**

- 「かんたん」（棚や柱なし・ぶつかっても減点なし）のオン／オフ
- あそびかた（基本のチュートリアル）
- ステージ Lv1〜7：前のステージをクリアすると次が遊べます
- ほかのあそび：エンドレス／2人であそぶ／誘導員になる
- 「実機配置」の設定にしていても、あそぶではボタン操作になります

**まなぶ**

1. チュートリアル（基本操作と、軽トラ積載・荷降ろし・港の積載・棚入れ）
2. 作業別トレーニング（作業・モード・ステージ・レベルを選んで採点つきで練習。レベルは自由に選べます）
3. 検定コース（準備中：講習機関のコースと採点表に合わせて作成予定）
4. 練習モード（講師向け・自由配置）
5. 操作と安全のポイント

ゲーム中は「メニュー」→「タイトルに戻る」で、そこまでの状態が保存され、「つづきから」で再開できます。結果画面の「メニューに戻る」で、遊んでいた入口（あそぶ／まなぶ）に戻ります。

> このアプリは学習を助けるためのものです。フォークリフトを運転するには、最大荷重1トン以上は「運転技能講習」、1トン未満は「特別教育」の修了が必要です（公道を走るには運転免許も必要です）。実際の操作は、講習や職場の指導に従ってください。

## チュートリアル

「あそぶ」の「あそびかた」ですぐに基本操作を始められます。「まなぶ」の「チュートリアル」では、次の項目を選んでから始めます。

- **操作方法**：ボタン操作／実機配置
- **練習する作業**：基本操作／軽トラ積載／荷降ろし／棚入れ／港の積載
- **始める場所**（基本操作のみ）：1. 最初から（全19手順・約4分）／2. 荷を取る（荷物の前から）／3. 運んで下ろす（荷を持った状態から）
- **練習する荷物**：小・中・大・ワレモノ・長尺・段ボール・ぬいぐるみ・水槽・鮮魚・ドラム缶（作業によって選べる荷物が変わります）

画面の指示と光るボタンに沿って進めます。最後の「爪を抜く」まで終えると完了画面が出ます。手順より先の操作をしてしまった場合は、自動でそこまで手順が進みます。歩行者は出てきません。実機配置では、レバーとペダルの説明になり、手順に合わせてハンドルと荷役レバーの表示も自動で切り替わります（「フォーク操作へ」「走行に戻る」の手順はありません）。

## 作業の種類

「まなぶ」→「作業別トレーニング」で「作業」を選べます（誘導員モードはいまは構内運搬のみ）。エンドレスは「あそぶ」から遊びます。

| 作業 | 内容 |
|---|---|
| 構内運搬 | 床の荷物を、同じ番号の置き場へ運びます（これまでの内容） |
| 軽トラ積載 | 床の荷物を、軽トラの荷台（高さ約65cm）へ横から積みます。荷の底が荷台より上になるまで上げ、水平にして、ゆっくり入れて下ろします |
| 荷降ろし | トラックの荷台（高さ約1m）の荷を取り、床の置き場へ降ろします。持ち上げたらまっすぐバックして荷台から出し、それから下げます |
| 港の積載 | 港の平台（シャーシ・荷台 約1.25m）に積みます。荷の四隅を**固定金具4か所**に合わせないと固定できません（ずれていると「固定できません」と出るので、少し持ち上げて合わせ直します）。許されるずれはレベルが上がるほど小さくなります（Lv1 8cm → Lv7 3cm、向きは3°→1.5°）。Lv4からは幅2.4mの重い「コンテナ風の箱」を扱います |
| 棚入れ・棚出し | 屋内の3段の棚（下段・中段 約1.2m・上段 約2.4m）へ荷を入れる・取り出す。段の高さより上まで上げ、水平にしてゆっくり入れ、少し下げて抜きます。上段ほど荷揺れに注意 |
| エンドレス | 荷物が次々に出てきます。走る・荷を上げ下げするほど燃料が減り、**ドラム缶を運ぶと燃料が40%回復**します。燃料が0になるか、事故・衝突・ワレモノ破損が合わせて3回でおしまい。何個運べたかが記録になります |

荷台では、荷の一部がはみ出していたり、あおりに乗っていたりすると下ろせません。港の積載では、荷を持って平台に近づくと金具の色が変わり（緑＝合っている／赤＝ずれている）、荷役ビューに「金具のずれ 最大◯cm」が出ます。サイドシフトとインチングで細かく合わせます。荷を高く上げたまま走ると注意・減点になります。

## 荷物の種類とごほうび

| 荷物 | 気をつけること |
|---|---|
| 段ボール | 基本の荷 |
| ぬいぐるみ | 軽いけれど背が高く、荷揺れしやすい |
| 水槽 | ワレモノ。傾けたり、急ブレーキ・急カーブをすると水がこぼれる |
| 鮮魚 | 氷水入りで傾けるとこぼれる。時間がたつと鮮度が落ちる |
| ドラム缶 | 重くて止まりにくい。前に傾けると転がり落ちる。エンドレスでは燃料になる |
| コンテナ風の箱 | 幅2.4m・高さ1.25mで重い。港の平台の固定金具4か所に合わせて載せる |

ぬいぐるみ・水槽・鮮魚を、ぶつけず・こぼさず・落とさずに運ぶと、ごほうび（ぬいぐるみ、水槽の飾り、魚）がもらえます（チュートリアルを除く）。「図鑑・実績」の「コレクション」で、飾り棚と水槽（もらった魚が泳ぎます）を見られます。

## 爪で床を削らない・傾けてはいけない荷

- 爪は床から少し（2〜5cm）浮かせて走ります。床や荷台に爪を着けたまま動くと「爪で床を削った」として注意・減点（初心者コースは注意のみ）。前傾にすると爪の先が下がるので注意します。荷を下ろしたあとは、爪を少し下げて荷から離してから抜きます。
- 水槽・鮮魚は、後傾にせず、水の面が水平になるようにチルトを合わせて運びます。坂の上では、坂の分だけ逆にチルトを傾けて水平を保ちます。爪を差し込む・荷を下ろすときは、地面（坂）に対して爪を平行にします。

## 練習モード（自由配置）— 講義・自主練習向け

「まなぶ」→「練習モード（講師向け）」で、荷物と置き場を好きな場所に置いて練習できます。

1. 「＋ 荷物」で荷物の種類を選び、地図をタップして置きます。続けて、その荷物の置き場をタップします（荷台や棚の上にも置けます。棚は「棚の段」で下段・中段・上段を選びます）。
   「トラック・棚」で軽トラ（荷台 約65cm）・トラック（荷台 約1m）・港の平台（荷台 約1.25m、置き場の四隅に固定金具が付きます）・3段の棚を選び、好きな場所をタップして置きます（3台まで）。「↻ 90°回す」で荷を積む側（黄色い矢印）の向きを変えられ、ドラッグすると荷台の上の荷物もいっしょに動きます。
2. 「選ぶ・動かす」で、荷物・置き場・フォークリフトをドラッグで動かせます。「↻ 90°回す」「削除」も使えます。「スタート位置」でフォークリフトの位置と向きを決めます。
3. 「場所と表示の設定」で、棚・柱、坂、歩行者・動物の出方、ステージを選べます。
4. 「この配置で運転」で始めます。ゲーム中の「メニュー」→「配置を編集（いまの位置から）」で、途中の状態から配置を直せます。終わったら「配置に戻る」で何度でも同じ配置から練習できます。

**保存と共有**

- 「保存・読み込み」で、名前を付けて端末に保存できます（30件まで）。
- 「URL・QRで共有」で、配置入りのURLとQRコードを作れます。受講者がQRを読み取ると、同じ配置の練習モードが開きます。コードを貼り付けて読み込むこともできます。

**講師用の解説表示**

上方ビューを大きく表示し、爪の高さ（荷台からの高さ）、チルト（車体に対して／坂では重力に対して）、速度、人・動物までの距離、荷揺れを画面に出します。プロジェクターでの説明に使えます。

## 画面の切り替え

ビューの右上のボタンで、上方ビューと運転席ビューの「⇄ 切替」、小窓の「あり／なし」、小窓の位置（右上・左上・左下・右下）をゲーム中でも変えられます。選んだ表示は次回も残ります。

## 3つのモード

| モード | 内容 |
|---|---|
| 運転者モード | 自分でフォークリフトを運転します。AI誘導員が「停止」「徐行」などの合図で補助します。 |
| 誘導員モード | 合図を出してAI運転者を誘導します。ボタンのほか、**声**でも合図できます。 |
| 2人プレイ | 1台のスマホで、1人がボタンで運転し、もう1人が声で誘導します。聞き取った合図が画面に大きく出ます。 |

## ゲーム中のメニュー

画面上の「メニュー」を押すと一時停止し、「再開する」「最初からやり直す」「タイトルに戻る」を選べます（PCでは P または Esc）。チュートリアル中は「チュートリアルを最初から」になります。

## 操作（運転者モード・2人プレイ）

### 走行モード（初期設定：ボタン操作）

| ボタン | 内容 |
|---|---|
| ◀ ▶（左手） | ハンドル。押している間だけ切れ、離すとまっすぐに戻ります。 |
| 前進／バック（右手） | 押している間だけ進みます。押し始めはゆっくり、押し続けると制限速度まで加速します。 |
| フォーク操作 | 荷物の前や置き場で押すと、フォーク操作モードに切り替わります。切り替えどきになるとボタンが光ります。 |
| 指差確認 | 歩行者通路の手前で止まって押すと加点されます。 |

開始画面で、スティック操作（かんたん／地図基準／車体基準）や、モード切替のない「実機配置」にも切り替えられます。

### 実機配置（モード切替なし）

開始画面の「操作」で「実機配置」を選ぶと、実際のカウンターバランス型フォークリフトに近い操作になります。走行と荷役を切り替えずに、ハンドル・レバー・ペダルを同時に使います。

| 場所 | 操作 | 内容 |
|---|---|---|
| 左手 | ◀ ▶ ハンドル | 後輪で曲がります（尻振りあり） |
| 右手 | 前後進レバー F・N・R | F＝前進、N＝中立、R＝後進。走行中は切り替えられません（止まってから） |
| 右手 | リフトレバー | 押す＝下げ、引く＝上げ（押している間だけ動きます） |
| 右手 | チルトレバー | 押す＝前傾、引く＝後傾 |
| 右手 | サイドシフトレバー | 爪を左右に動かします |
| 左足 | インチング | アクセルと一緒に踏むと、とてもゆっくり進みます（差し込み・抜き取り用） |
| 右足 | ブレーキ | 強く止まります。アクセルを離しただけだと、ゆっくり惰性で止まります |
| 右足 | アクセル | 前後進レバーの向きへ進みます。N のままでは進みません |

レバーは左から「リフト → チルト → サイドシフト」、ペダルは左から「インチング → ブレーキ → アクセル」の順に並べています。レバーの「押す・引く」は、運転席から見て前へ押す・手前へ引く向きです（画面では上が押す、下が引く）。

- 荷物や置き場に近づくと、自動で視線が下がり、運転席から爪先をのぞき込む見え方になります。実車と同じく、マスト・リフトシリンダー・荷受け（バックレスト）で爪先や差し込み口の一部が隠れます。補助表示がオンなら、画面をタップすると図解の荷役ビューで確かめられます（もう一度タップで戻ります）。
- スマホの縦画面ではボタンが多くなるので、「荷役レバーを表示／ハンドルを表示」で、ハンドルと荷役レバー（リフト・チルト・サイドシフト）の表示を入れ替えられます。前後進レバーとペダルは常に表示されます。入れ替えるのはボタンの表示だけで、車の動きは変わりません。荷物に近づくと切り替えボタンが光ります。全画面の横向きでは、すべてのボタンを同時に表示します。
- その場で車体を回すことはできません。向きがずれたら、少し下がってハンドルで入り直します。
- R に入れると運転席ビューは後方に切り替わり、後退警報音が鳴ります。
- PCでは 1・2・3 で F・N・R、↑ アクセル、↓ ブレーキ、Shift インチング、Q/E リフト、Z/X チルト、, . サイドシフトです。

### 練習用の補助表示と本番の視界

開始画面の「上方ビューを表示する」と「補助表示」で、見え方を切り替えられます。チュートリアルでも上方ビューは外せます（補助表示は常にオン）。選んだ設定は次回も残ります。

| 設定 | オン（練習） | オフ（本番） |
|---|---|---|
| 上方ビューを表示する | 上方ビュー（小窓）あり | なし（運転席ビューのみ） |

| 表示 | 補助表示オン | 補助表示オフ |
|---|---|---|
| 進路予測線・尻振りの赤い帯 | あり | なし |
| フォーク操作中の映像 | 図解の荷役ビュー（タップで運転席の視点に切替） | 運転席から爪先を見下ろす視点のみ |

本番では、実際の運転者と同じく運転席から見える範囲だけで、爪先とパレットの差し込み口を見て合わせます。誘導員モードの上方ビューは、誘導員の目線として表示されます。

### 坂道とチルト（Lv4以上）

Lv4以上では、荷物置き場の周りが上り坂になります（Lv4・5：約7%、Lv6・7：約10%）。上方ビューに上り方向の矢印と勾配が表示され、運転席ビューも坂に合わせて傾きます。

荷の安定は「チルト＋坂の角度」＝地面（重力）に対して荷がどちらに傾いているかで判定します。

| 状況 | 判定 |
|---|---|
| 上り坂を前進 | 前傾ぎみでも、地面に対して荷が前に傾いていなければOK |
| 下り坂を荷を積んで前進 | 注意＋減点（−3）。荷を坂の上側にして、後進で下りるのが正しい |
| 平地 | 荷を持ったら後傾で走行を推奨 |

### 曲がり方と尻振り

実車と同じく、後輪で曲がります。ハンドルを切ると前輪の車軸付近を中心に向きが変わり、車体の後ろが外側へ大きく振り出します（尻振り）。止まったままでは向きは変わりません。

- 上方ビューに、後ろが振り出す範囲を**赤い帯**で表示します。
- 振り出す範囲に人や動物がいると、AI誘導員が「尻振り注意」の合図を出します。
- 車体の後ろが当たった事故は「尻振り」として記録され、結果画面にも件数が出ます。

（スティック「かんたん」とフォーク操作の ↺ ↻ は、初心者向けにその場で向きを変えられます。）

### フォーク操作モード（荷を取る・置く）

| ボタン | 内容 |
|---|---|
| ◀ 爪を左へ／▶ 爪を右へ | 爪だけを左右に動かします（サイドシフト、±15cm）。 |
| ↺ 左に回す／↻ 右に回す | 車体を少しずつ回して向きを合わせます。 |
| 前進／バック | 押し始めはゆっくり、長押しで加速します（最大約2.7km/h）。荷物の近くではゆっくりのままです。 |
| 上げ／下げ | 押している間だけ爪が上下します。 |
| 前傾／後傾 | チルト。差し込むときは水平、運ぶときは後傾。 |
| 走行モードに戻る | 運転の操作に戻ります。 |

画面は「荷役ビュー」に切り替わり、左に爪と荷物を真上から拡大した図、右にパレットの差し込み口と爪を正面から見た図（高さは2倍で表示）が出ます。「向き」「左右」「爪の高さ」「差し込み％」が数値で表示され、次にやることも案内されます。

- **差し込む**：向き・左右・高さ（差し込み口は床から2〜12cm）を合わせ、爪を水平にしてから前進します。ずれていると爪がパレットに当たります。
- **持ち上げる**：75%以上差し込んでから「上げ」。浅いと持ち上がりません。
- **抜く**：荷を下ろしたら、爪を一番下まで下げてからバックします。爪が当たったまま抜くと荷を引きずります。
- 爪が刺さっている間は、車体を回したり曲げたりできません。向き・左右・高さが合わないまま当たった場合は「刺さった」扱いにならないので、バックすればいつでも離れられます。

**初心者コース**（初期設定でオン）：棚と柱がなくなり、壁や荷物にぶつかっても減点されません。位置合わせの許容範囲も広くなります（通常：左右±6cm・向き±3°／初心者：左右±12cm・向き±6°）。人や動物との接触は減点されます。

PCでは、矢印キーで走行、G でフォーク操作の切替（フォーク操作中は矢印キーで低速移動とサイドシフト、Q/E で上げ下げ、Z/X で前傾・後傾、, . で回転）、C で指差確認ができます。

## 4つのステージ

| ステージ | 特徴 |
|---|---|
| 標準倉庫 | 明るい屋内倉庫。まずはここから。 |
| 冷凍倉庫 | 床が凍って滑りやすく、止まるまでの距離が伸びます。ペンギンがよく出ます。 |
| 夜間 | ライトの届く範囲しか見えません。青色警告灯が床を照らします。 |
| 屋外ヤード（雨） | 雨で視界が悪く、路面も少し滑ります。棚はコンテナに変わります。 |

## 見どころ

- **上方ビュー**と**運転席ビュー**の2画面。荷物が大きいほど運転席から前が見えなくなり、上方ビューには運転者の**死角**を赤く表示します。
- 荷物は「小」「中」「大」に加え、**ワレモノ**（ぶつけると破損）と幅2.4mの**長尺物**が登場します。
- 背の高い荷を積んで速く曲がると荷が揺れ、「荷揺れ」ゲージが振り切れると**荷崩れ**します。爪を後傾にして運ぶと荷崩れしにくくなります。
- 歩行者通路の手前で止まって**指差呼称**（ボタン、または声で「右よし、左よし」）をすると加点されます。
- 合図には実際の現場のような**笛の音**が鳴り、後進中は**後退警報音**が鳴ります。
- スマホでは映像・合図・操作ボタンが1画面に収まり、スクロールなしで遊べます。小窓のあり／なし、全画面モードにも対応。横向きでは両手持ち操作ができます。

## レベル（チュートリアルから順にステップアップ）

チュートリアルのあとは Lv1 から始めて、1つずつ覚えることを増やしていきます。B以上でクリアすると「次のレベルへ」が出て、開始画面のレベル一覧にも ✓ が付きます（次に開いたときは、クリアした次のレベルが選ばれます）。

| レベル | 荷物 | ここで覚えること | 坂 | おじゃま虫 |
|---|---|---|---|---|
| Lv1 入門 | 小 ×1（まっすぐ向かいへ） | 取る・運ぶ・下ろすの流れ | なし | 作業員・ひよこが、ときどき |
| Lv2 初級 | 中 ×2 | 荷で足元が隠れる／指差確認 | なし | ＋猫・コーンちゃん |
| Lv3 中級 | 中・大 | 前が見えない荷は後進で運ぶ／荷揺れ | なし | ＋犬 |
| Lv4 中級＋ | ワレモノ・中・大（斜め向かいへ） | ワレモノの扱い／坂道とチルト | 約7% | 全種類 |
| Lv5 標準 | ワレモノ・中・大・長尺 | 長尺物（幅2.4m） | 約7% | 全種類・多め |
| Lv6 上級 | 同上 | 運転者の反応が遅れ、人以外に気づかない | 約10% | 全種類・速い |
| Lv7 実戦 | 同上 | 運転者は自分で止まらない。誘導員の「停止」が頼り | 約10% | 全種類・とても多い |

誘導員モードでは、レベルが上がるほどAI運転者の速度と反応の遅れが増えます。

## 採点

接触事故 −30、荷崩れ −15、ワレモノ破損 −20、衝突 −5、爪がパレットに当たる −3、荷を引きずる −2、ヒヤリハット −5、速度超過（6 km/h 超）2秒ごとに −1、指差呼称をせずに歩行者通路を横断 −3。点数は100点満点です。指差呼称をすると、それまでの減点を3点まで取り戻せます（100点を超えることはありません）。終了後に S〜C の評価と改善のアドバイスが表示されます。
